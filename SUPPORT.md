# Support

## Community support (free, open source)

- **Questions, ideas, show-and-tell** → [GitHub Discussions](../../discussions)
- **Bug reports** → [Issues](../../issues/new/choose) (please use the bug form — reproduction steps matter)
- **Security** → see [SECURITY.md](SECURITY.md), never public issues

We're a small team and read everything. Response times are best-effort — usually within a day on weekdays.

## Self-hosting

Start with [docs/self-hosting.md](docs/self-hosting.md) and the annotated `.env.example`. If the docs are wrong or missing something, that's a bug — open an issue.

## Commercial support

[Paylo One](https://paylo.one) runs Pilot as a managed service: we operate the infrastructure, pre-configure the integrations, and handle updates and backups. If you'd like support SLAs or managed hosting, start at [paylo.one](https://paylo.one).
